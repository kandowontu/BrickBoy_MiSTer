# Contributing

Please open an issue before substantial display-model changes. Changes should preserve default output unless they intentionally track a documented BrickBoy upstream change.

Hardware-facing pull requests should include:

- the Quartus version used;
- full compile success;
- worst-case setup and hold slack;
- DE10-Nano test results and video output used;
- the SHA-256 of any proposed release RBF.

Do not approximate unpublished BrickBoy effects under an upstream feature name. Clearly label independently designed effects as MiSTer extensions.
